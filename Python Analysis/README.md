# Python Analysis

## Overview
This folder contains the Python programs developed for data cleaning, preprocessing, and exploratory data analysis of the retail sales dataset.

Python libraries such as Pandas and NumPy were used to process the dataset, examine data quality, and calculate important statistical information.

## Tools & Libraries
- **Python:** Programming language used for data analysis.
- **Pandas:** Data manipulation and preprocessing.
- **NumPy:** Numerical calculations and statistical operations.

## Programs Included

### 1. Data Cleaning
This program performs:
- Dataset loading and inspection.
- Checking missing values.
- Identifying and removing duplicate records.
- Examining data types.
- Preparing the cleaned dataset.
- Comparing original and cleaned data.

### 2. Exploratory Data Analysis (EDA)
This program performs:
- Descriptive statistical analysis.
- Sales and profit calculations.
- Category-wise performance analysis.
- Region-wise analysis.
- Sub-category profitability analysis.
- Discount and profit relationship analysis.

## Outcome
Python helped improve dataset quality and extract useful information for further analysis using Excel and Tableau.

## Purpose
The Python analysis stage established a reliable dataset and provided a foundation for generating meaningful business insights.
