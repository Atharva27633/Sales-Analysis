# Dataset

## Overview
This folder contains the datasets used for the Retail Sales Analysis project.

The dataset includes retail transaction information that helps analyze sales performance, profitability, product categories, customer segments, discounts, and regional performance.

## Files Included

### 1. Original_Dataset.xlsx
Contains the original retail sales data before performing any data cleaning or preprocessing.

### 2. Cleaned_Dataset.xlsx
Contains the cleaned dataset prepared using Python. It was used for further exploratory data analysis and visualization.

## Dataset Information
The dataset contains information related to:
- Order and customer details.
- Product categories and sub-categories.
- Sales and profit.
- Discounts and quantities.
- Regional and geographical information.
- Customer segments.

## Data Preparation
The original dataset was examined and processed to improve data quality and consistency. The cleaned dataset was then used for further analysis.

## Purpose
The dataset serves as the foundation for Excel analysis, Python-based data processing, and Tableau visualization.

**Note:** Both original and cleaned datasets are included for comparison and transparency.
