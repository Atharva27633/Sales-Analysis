# Data Visualization Analysis

## Overview
This folder contains the visual representations and Tableau dashboards developed for the Retail Sales Analysis project.

Tableau was used to convert the analyzed data into visual insights, making it easier to understand sales performance, profitability, and regional business trends.

## Tool Used
**Tableau:** Used for creating charts, comparing business performance, and developing interactive dashboards.

## Visualizations Included
- Sales performance by region.
- Profit analysis by product category.
- Sub-category-wise profitability.
- Discount versus profit analysis.
- Overall sales and profit comparisons.

## Dashboard Features
- Visual comparison of sales and profitability.
- Category and regional performance analysis.
- Interactive filters, where applicable.
- Charts designed to highlight important business insights.

## Key Insights
- Identified high-performing regions and product categories.
- Highlighted low-profit and loss-making sub-categories.
- Examined the relationship between discounts and profitability.

## Purpose
The visualization stage presents the findings in an easy-to-understand format and helps communicate business insights through charts and dashboards.

## Files Included
This folder contains the Tableau workbook and exported dashboard images for reference.
